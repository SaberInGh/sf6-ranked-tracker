# SF6 排位对局记录工具

一个用于记录和分析《街头霸王6》排位赛对局数据的本地 Web 工具。

## 功能特性

- 📊 **对局记录**：记录每场排位赛的对手、胜负、赛前/赛后 LP
- 📈 **数据可视化**：柱状图 + 趋势线展示分数变化
- 🏆 **段位显示**：自动根据 LP 计算并显示当前段位和星级
- 📅 **日期归档**：按日期分组查看对局记录
- 📉 **差值分析**：每局 LP 变化一目了然，升段/升星标注
- 👥 **对手统计**：汇总各对手的战绩和胜率
- 💾 **本地存储**：数据保存在浏览器 localStorage，无需服务器
- 📤 **导入导出**：支持 JSON 格式的数据备份和恢复

## 使用方法

1. 直接在浏览器中打开 `sf6_tracker.html`
2. 选择对手、胜负结果，输入赛前/赛后 LP
3. 点击"添加对局"保存记录
4. 查看统计数据和图表分析

## 文件说明

- `sf6_tracker.html` - 主工具页面
- `chart.umd.min.js` - Chart.js 图表库（本地版本）
- `match_analysis.html` - 对局数据分析面板
- `bar_chart.html` - 柱状图示例

## 技术栈

- 纯前端实现，无需后端
- Chart.js 4.4.7 用于图表渲染
- localStorage 用于数据持久化
